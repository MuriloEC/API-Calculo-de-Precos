# 🧮API de Calculadora de Preços de Equipamentos Industriais

API desenvolvida para cálculo de preços de equipamentos utilizados na indústria química, desenvolvido com **FastAPI**.  

---

## 🚀 Tecnologias Utilizadas

### Backend
- **FastAPI** — framework moderno e rápido para criação de APIs com Python.
- **Uvicorn** — servidor ASGI leve e de alto desempenho para testes.
- **NumPy / Pandas** — manipulação e cálculos de dados.
- **SQLAlchemy** — ORM para persistência de dados e acesso ao banco de dados do Firebase.
